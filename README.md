# HTML5 Slot Machine — Customized Educational Version

This project is a customized and modified version of the original **HTML5 Slot Machine** project by **Johannes Kronmüller**.

The original project was used as a starting point for personal educational purposes. The code has been modified and the visual assets have been replaced for this custom version.

## Customizations

- Custom page background.
- Custom `bg.jpg` and `bg_small.jpg` background images.
- 40 custom PNG slot symbols (`z1.png` to `z40.png`).
- Five slot reels retained from the original project.
- Random selection of symbols from the 40 custom symbols.
- Prevention of duplicate symbols within the three visible symbols of each reel.
- Removal of the original jackpot display.
- Additional visual and layout modifications.

## Installation

Install the project dependencies:

```
npm install
```

## Development

Start the local development server:

```
npm start
```

Then open:

```
http://localhost:8080
```

## Production Build

Create a production build with:

```
npm run build
```

## Project Structure

The custom slot symbols are located in:

```
src/assets/symbols/png/
```

The files are named:

```
z1.png
z2.png
...
z40.png
```

The page backgrounds are located in:

```
src/assets/bg.jpg
src/assets/bg_small.jpg
```
